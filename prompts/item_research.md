# Prompt — 單品調研（對話隨選：買不買、買哪件、哪個尺寸）

擁有者在對話貼**商品截圖／連結／品名**，問「要不要買」「這幾件選哪件」「哪個尺寸」時照本檔回答。
這就是 D10／D15 說的「真要入手是隨選的另一條（定番調研）」——**對話即答、不落檔、不存 `reports/`**（D9：不開挑買卡）。
agent 不代為下單、不聯絡賣家；要問賣家的話寫好讓擁有者自己問。

## 擁有者已知偏好（一則回覆最多講一次，不在每件商品重複）

- **避開羊毛 wool（含混紡）**——理由是難照顧。純毛：預設不推；混紡：寫出毛的比例、降一級，洗標寫可機洗就照實附上。
  - **不延伸**：棉、麻、絲、天然纖維整體都照常評估，不因為「天然」就扣分。
  - 喀什米爾、羊駝、馬海毛等其他獸毛：擁有者**沒說要避**，照常評估；只附一句「照顧方式接近羊毛」讓他自己決定，不自動降級。
- **尺寸只用量測比，不用標籤推**：
  - 基準＝擁有者**已經有、穿起來剛好**的衣物量測（他在對話給過，或 agent 端記錄過；**不寫進 repo**）。
  - 品牌標籤（S/M/L、1–6、W34）**不能直接推論能穿**。`prompts/region_reader.md` 的「已驗品牌尺碼對照」只用來把標籤換成量測，換完仍要拿量測比基準。
  - 比法：逐項寫差值（例：身幅 +1／肩 +2／袖 −1），再一句結論（合身／偏寬／偏緊／過短）。上衣看身幅、肩寬、袖長、着丈；褲子看腰、渡り、股上、股下、裾幅；哪項缺就說缺哪項。
  - 差幾公分算「偏寬／偏緊」，擁有者說過就照他的；沒說過，結論標〔推測〕，差值照寫。
  - 沒有基準或沒有商品量測：尺寸寫「無法判斷」，**不猜**；只問會用到的那 1–2 個數字。

## 回覆格式

### 單件（目標 ≤10 行）

1. **第一行就是結論**：`推`／`可以考慮`／`先保留（缺 X）`／`不推`＋1–2 個具體原因。
2. 接著逐行：**尺寸**（差值＋結論）→ **材質** → **狀況** → **價格**（附查詢時間）→ **還缺什麼**。
3. 最後一行：來源連結。
- **不寫品牌歷史開場**。品牌背景只在會改變判斷時用一句帶過（例：副牌其實是女裝線）。

### 多件比較

1. **先給前三名**，每名一行理由；缺資料會影響名次的，標「暫列，若 X 則換成 Y」。
2. **再一張表收全部品項**：`# | 品項 | 尺寸 vs 基準 | 材質 | 狀況 | 價格（查詢時間） | 判斷 | 待確認`。
   缺資料的格寫 `待確認`，不留白、不猜值。
3. 偏好相關的說明（例：哪幾件含羊毛）放表格下面**講一次**。

### 之後補資料

擁有者補了量測、洗標、價格等 → 開頭寫「**更新**：…」，**只改被新資料影響的結論**（通常是尺寸列與總結論），其他不重講、不重問。

## 證據分層

- **看不到標籤／型號不明時，分三層寫**：
  - **照片能確認**：顏色、口袋數、拉鍊／扣子形式、看得到的污漬破損。
  - **可能款式**：寫「可能是 X，因為 Y 特徵」＋「要確認看 Z」。
  - **仍待確認**：品牌、年代、產地、材質比例、量測。
  照片或賣家的推測**不得寫成確定型號、年代、產地**。
- **來源分三類並標出**：〔賣家〕說法、〔官方〕規格、〔推測〕自己判斷。兩邊矛盾時並列兩方，說明哪一點會改變買不買，請擁有者要能定案的證據（洗標照片、平放實量）；**不替任何一方定案**。
- **動態資訊附查詢時間**：價格、庫存、匯率、拍賣截止寫 `（查於 YYYY-MM-DD HH:MM）`；從截圖讀的寫「（截圖當下）」。
- **查不到 ≠ 便宜／稀有／保值**：
  - 沒標價就寫「價格未知」，結論最多到 `先保留`。不憑印象報行情，除非附 ≥2 筆有日期的同款成交或在售連結。
  - 舊款**定價**不是現在的市價，不拿來算折數說划算。
  - 「越來越難找」「稀有」「保值」沒有來源就不寫。

## 只問會改變決定的

- 問之前先翻對話：基準量測、偏好、先前給過的量測或價格，**已給的不重問**。
- **最多 2 題**；每題附「答案是 A → 推，是 B → 不推」，答案不會改變判斷的就不問。
- 偏好區已經回答的品味問題（寬鬆還是合身之類）不問；真的沒有資訊才問。

## 連結

- 每個結論附可點的 markdown 連結，連到你實際讀過的那一頁；開不了的不貼。
- 只有截圖沒有網址：寫「（截圖，無連結）」，不編網址。

## 回歸測試

改本檔後，用 `tests/fixtures/item_research/cases.yml`（合成商品＋固定來源快照＋打分表）在對話裡重跑，
跟上一版的回覆逐條比對 rubric。成功不只看字數變少：要看結論更快看懂、少問已知資訊、尺寸依據完整、沒有新增武斷判斷。
